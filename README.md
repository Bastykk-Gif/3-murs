# 3 MURS

Jeu de blocs pour navigateur, jouable sur smartphone, PC (clavier) et manette.

Les pièces tombent sur une tour à 3 murs. Une ligne complète ne disparaît pas : elle reste soudée, et tu choisis vers quel mur pivoter. Quand chacun des 3 murs a au moins 4 lignes prêtes, tout s'écroule d'un coup. Chaque ligne en plus avant l'écroulement ajoute 50 % au gain.

## Jouer

Ouvre `index.html` dans un navigateur, ou la page GitHub Pages du dépôt si elle est activée.

## Commandes

| Action | Clavier | Manette | Tactile |
|---|---|---|---|
| Déplacer | flèches gauche / droite | croix ou stick | croix |
| Descendre | flèche bas | croix bas | croix bas |
| Chute instantanée | Espace | croix haut | croix haut |
| Tourner | flèche haut ou X | B | bouton rose |
| Tourner (inverse) | W (AZERTY) ou Ctrl | A | bouton bleu |
| Réserve | C ou Maj | LB / RB | bouton RÉSERVE |
| Pause | Échap | Start | bouton PAUSE |

## Fichiers

- `index.html` : le jeu (version courante, style cartoon)
- `sf.js` : échantillons d'instruments pour la musique
- `versions/v1-realiste/` : ancienne version au rendu réaliste (acier, fumée, orchestre)
